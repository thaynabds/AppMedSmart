**Your intelligent assistant for health management and medication adherence.** 🏥✨

MedSmart is a mobile application developed to help patients organize their medications 💊, receive real-time alerts 🔔, and track their treatment adherence in a simple and secure way. 📱💜

![Project Cover](https://raw.githubusercontent.com/thaynabds/AppMedSmart/refs/heads/main/Med%20Smartt.png)

---

## 🎯 About the Project

**MedSmart** was created to reduce medication administration errors ❌ and increase autonomy for patients with complex treatment routines. With intuitive design 🎨 and accessibility focus ♿, the app centralizes all important health information in one place. 🌟

**Developed by:** Student of the **Systems Analysis and Development** course 💻 at **Senac Recife-PE Faculty** 🎓, 2025

**Project Status:** 🚧 High-Fidelity Prototype in Figma

![Med Smart Solution](https://raw.githubusercontent.com/thaynabds/AppMedSmart/refs/heads/main/Solução.png)

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 💊 **Medication Management** | Complete registration with name, dosage, schedules, and notes |
| 🔔 **Smart Alerts** | Push notifications to never miss a dose |
| 📊 **Adherence History** | Detailed record of taken and missed doses |
| ❤️ **Vital Signs Monitoring** | Track blood pressure, blood glucose, weight, etc. |
| 📅 **Medical Agenda** | Organize appointments and exams |
| 🎨 **Accessible Interface** | Clean and intuitive design ♿ |
| 🎙️ **Voice Assistant** | For better accessibility |
| 👥 **Caregiver Profile** | For family members to manage patient health |

## 🌍 ESG Impact 🌱

### 🌿 **E – Environmental**
- ♻️ Reduces medication waste
- 💧 Prevents incorrect use and extra consultations, saving hospital resources

### 👥 **S – Social**
- 📱 Promotes digital inclusion and health literacy 📚
- 👴 Helps elderly people and those with low education
- ❤️ Improves treatment adherence and quality of life 🌟

### ⚖️ **G – Governance**
- 🔒 Ensures ethics, transparency, and data protection (LGPD/GDPR) 🛡️
- 🏥 Facilitates public health planning by reducing disease recurrence and medical errors

## 👥 Target Users

| Audience | Need |
|----------|------|
| 🚶 **Patients with difficulties** | Low education, functional illiteracy, difficulty following medical prescriptions |

| 👨‍👩‍👧 **Caregivers** | Need all clinical data in one place + medication reminders ⏰ |

## 🚀 How to Run the Project

### 📋 Prerequisites
- Python 3.10 or higher installed ✅

### 📝 Step by step

```bash
# 1. Clone the repository
git clone https://github.com/thaynabds/medsmart.git
cd medsmart

# 2. Create a virtual environment (recommended)
python -m venv venv
venv\Scripts\activate # Windows
# source venv/bin/activate # Linux/Mac

# 3. Install dependencies
pip install flet

# 4. Run the application
python main.py
```
